Gym Tracker (standalone app)

HOW TO USE
1. Upload this whole folder to any web host (Netlify Drop, GitHub Pages, Vercel, or your own server). It must be served over https.
2. Open the link on the phone, then choose "Add to Home Screen" (Android Chrome: Install app). It then opens like a normal app and works offline.

NOTES
- All data is stored on the phone that uses it (browser storage). Use Dashboard > Backup > Export regularly, and Import to restore on a new phone.
- No login is built in, so only share the link with the gym owner.
- To publish on the Google Play Store later, wrap the hosted link with PWABuilder (pwabuilder.com) or Capacitor.
